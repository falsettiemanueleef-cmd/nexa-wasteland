# NEXA: WASTELAND

**Android-first 2D Idle RPG** built with Godot 4 and GDScript.

## Project status
Early development — repository bootstrap.

## Vision
After **The Collapse**, the player reactivates the abandoned NEXA-01 bunker, gathers resources, prepares expeditions into a hostile wasteland, and uncovers fragments of the old world.

## Core design
- Genre: 2D idle RPG, post-apocalyptic setting
- Platform: Android first
- Engine: Godot 4, GDScript, Compatibility renderer
- Combat: automatic attacks with tactical player abilities
- Languages planned: Italian, English, Spanish, French, German

## MVP
- Bunker hub with Command Center and Storage
- Three map zone slots; first zone playable
- Expedition and basic automatic combat
- One player ability, health bars, victory/defeat
- Resource rewards and local save
- Offline progression capped at four hours

Online accounts, multiplayer, clans, PvP, ads, payments, and complex backend systems are outside the MVP.

## Getting started
Open this project in Godot 4 and run `scenes/main.tscn`.
